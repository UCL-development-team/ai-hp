# チャットログの保存

このリポジトリでは、Claude Code とのやり取りを `.claude.chat.log/` 配下に日本語のMarkdownログとして残す慣習がある。このスキルは、現在の会話をその慣習に沿って1ファイルにまとめて保存する。

## 手順

1. **会話全体を振り返る。** このセッションの最初のユーザー発言から現在までを通しで確認し、話の流れ（依頼→対応→やり取りの結果）を把握する。逐語の書き起こしではなく、要点を追った要約にする。

2. **タイトルを決める。** 会話全体の内容を一言で表す短い日本語タイトルを決める（例: 「ロゴ制作」「CLAUDE.md作成」）。このタイトルは、ログ本文の見出し（`# チャット履歴ログ — <タイトル>`）と、保存ファイル名の両方で **一言一句同じもの** を使う。

3. **保存先パスを決める。**
   - 現在日時を取得する（例: `date "+%Y-%m-%d_%H-%M-%S"`）。この日時は「ログを保存する時点」の日時であり、会話が始まった時刻ではない。
   - ファイルパスは次の形式にする: `.claude.chat.log/YYYY-MM-DD_HH-MM-SS_<タイトル>.md`
   - `.claude.chat.log/` ディレクトリが存在しない場合は作成する。

4. **ログ本文を書く。** 既存の実例（`.claude.chat.log/2026-08-05_17-20-17_ロゴ制作.md` がリポジトリにあれば参照する）と同じ構成に従う:

   ```markdown
   # チャット履歴ログ — <タイトル>

   このファイルは Claude Code とのチャットのやり取りを記録したものです。
   <このログの目的を一文で>ために保存しています。

   ---

   ## 1. <このやり取りの見出し>

   **User:** <ユーザー発言の要約>

   **Assistant:**
   <対応内容の要約。箇条書き可>

   ---

   ## 2. <次のやり取りの見出し>
   ...
   ```

   - 会話を意味のあるまとまり（依頼の単位）ごとに `## 番号. 見出し` で区切り、各セクションの間を `---` で区切る。
   - 各セクションは **User:** と **Assistant:** の要約を含める。ユーザー発言は要約しつつも、指示内容が正確に伝わるようにする。
   - コード全文やツール呼び出しの詳細は書かない。何をしたか・どんな結論になったかを書く。
   - 会話の結果、複数のファイルが作成・変更された場合など、まとめて一覧できると有用なときは、最後に `## 最終的な成果物一覧` のようなセクションを設け、表形式（`| ファイル | 説明 |`)で列挙する。該当しない場合は省略してよい。

5. **保存する。** 決めたパスにファイルを書き込む。

6. **保存先をユーザーに報告する。** 保存したファイルパスを伝える（例: `.claude.chat.log/2026-08-05_18-40-02_スキル作成.md に保存しました`)。
