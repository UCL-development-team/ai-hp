## 2. 黒背景用ロゴの作成依頼（1st トライ）

## 3. 白フチ（フリンジ）の除去依頼

**User:** （黒背景上のロゴ画像を添付）左のロゴ部も、右のフォント部も輪郭が白でギザギザにみえます。
この周りの白の外周は削除できますか？白背景では見えなかったと思いますが、そもそも不要です。

**Assistant:**
- 原因を特定：縁のピクセルが「白背景に馴染むよう」半透明ではなく **不透明(alpha=255)のまま白と混ざった色**で焼き込まれていた（境界のアルファが255→0に急に切り替わり、グラデーションで消えていなかった）
- 対処：透明領域から3px以上離れた「汚染されていない」内部の色を基準に、境界ピクセルをその色で塗り直す defringe 処理を実装（BFSによる距離変換＋最近傍の安全な色の伝播）
- 再度スクリーンブレンドを適用し `assets/ucl-logo-black.png` を上書き
- ズーム画像で白フチが解消されたことを確認

## 4. スケーラブルなロゴへの作り直し依頼

**User:** なんかボケボケで使えそうもないですね。
拡大縮小ができるように、ロゴは作り直して、フォントは元に近いものから再作成できますか？
元を参考に位置から作り直した方が良いですこれは。

**Assistant:**
ラスター画像の限界（拡大するとボケる）を踏まえ、完全にベクター（SVG）でゼロから再構築する方針に転換。

**アイコン部分の分析:**
- `ucl-logo.png` のアルファチャンネルを行ごとにスキャンし、アイコンの外形（六角形＝立体的なキューブ/ダイヤモンド形状）の頂点座標を実測
  - 頂点: T(28.5,0) / UR(57,26) / LR(57,34) / Bot(29.5,61) / LL(0,34) / UL(0,26)
  - 内部の面分割点 O ≈ (29,52)（上面・右面・左面の3面に分割されるキューブ構造と判明）
- `potrace`（純JS製ラスター→ベクタートレーサー）で試験的に自動トレース・自動配色も試みたが、階調が細かすぎてノイズの多い結果になったため不採用
- 各面の実際の色をピクセルサンプリングで取得し、手作業でクリーンな多角形＋グラデーションとして再構成
- 内側の「C」字型のくり抜き部分は、2つの円の差分ではなく **円弧（ストローク）** で表現することで、より自然な「C」の形状に調整

**文字部分:**
- ズームして確認した結果、クラシックなセリフ体太字（Times New Roman / Georgia 系）と判断
- `font-family: Georgia, 'Times New Roman', serif; font-weight: 700` でネイティブな `<text>` として再構築（トレースではなく実フォントを使用、拡大してもシャープ）
- 初期版はテキストが `viewBox` からはみ出してクリップされる不具合があったため、`viewBox` 幅を 350→400 に拡張し修正

**成果物:**
- `assets/ucl-logo.svg`（白背景用、元のブランドブルー配色）
- `assets/ucl-logo-black.svg`（黒背景用、同じ形状を明るめの配色に変換）
- `sharp` で1600px幅までラスタライズして拡大時にボケないことを確認
- 元のPNGとの比較画像を提示し、形状・配色・書体の近さを確認
