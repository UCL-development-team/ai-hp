# チャット履歴ログ — ワークツリーが原因で消せないブランチの削除

このファイルは Claude Code とのチャットのやり取りを記録したものです。
ローカルにだけ残った不要なコミット／ブランチが削除できなくなった際の原因と対処手順を残す目的で保存しています。

---

## 1. ブランチが削除できない問題の相談

**User:** `be4bd4a55fba6826e1d7770e3fc4a47b4a2b0e3c` というコミットについて、ローカルリポジトリにしかないものだが削除できなくなっている。以下のエラーが出る。

```
error: cannot delete branch 'claude/zealous-cori-3613df' used by worktree at '//Synology/Data/__Source_github_ucl/ai-hp/.claude/worktrees/zealous-cori-3613df'
```

**Assistant:**
まず状況を調査。

- `git worktree list` の結果、対象のワークツリーが **`prunable`** と表示されていた
- `.claude/worktrees/` 配下を確認すると、実体のディレクトリ `zealous-cori-3613df` は既に存在しない
- 一方で `.git/worktrees/zealous-cori-3613df` という **登録情報だけが残っていた**

原因はこれ。Git はこの登録情報を見て「ワークツリーがそのブランチを使用中」と判断するため、実体が無くてもブランチ削除を拒否していた。

続いて、消しても問題ないかを確認：

- `git log --oneline -3 be4bd4a` でコミット内容を確認
- `git diff --stat main...be4bd4a` の出力が **空** → `main` との内容差分なし。失われる変更はないと判断
- `git worktree prune -n -v`（ドライラン）で `Removing worktrees/zealous-cori-3613df: gitdir file points to non-existent location` を確認

---

## 2. 削除の実行

**Assistant:**
以下を実行して解決。

```
git worktree prune -v          # 実体のないワークツリー登録を削除
git branch -D claude/zealous-cori-3613df
```

結果：

- `Removing worktrees/zealous-cori-3613df: gitdir file points to non-existent location`
- `Deleted branch claude/zealous-cori-3613df (was be4bd4a).`

実行後の状態は、ワークツリーが本体（`//Synology/Data/__Source_github_ucl/ai-hp`）のみ、ブランチも `main` のみとなり、正常化を確認。

補足として、孤立した `be4bd4a` オブジェクト自体は reflog に残るが GC で自然に消える旨、即座に消す場合は `git reflog expire --expire=now --all && git gc --prune=now`（他の未参照オブジェクトも消えるため通常は不要）である旨を案内した。

---

## まとめ — 同じエラーが出たときの手順

| 手順 | コマンド | 目的 |
| --- | --- | --- |
| 1 | `git worktree list` | 対象が `prunable` になっていないか確認 |
| 2 | `git diff --stat main...<commit>` | 消して失う変更がないか確認 |
| 3 | `git worktree prune -n -v` | 何が削除されるかドライランで確認 |
| 4 | `git worktree prune -v` | 実体のないワークツリー登録を削除 |
| 5 | `git branch -D <branch>` | ブランチを削除 |
